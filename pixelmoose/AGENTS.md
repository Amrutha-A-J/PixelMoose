# Pixel Moose Studio Agents

## Project overview
- Single-page marketing + portfolio site built with Vite, React, and Material UI.
- Brand direction: bold, modern, prairie-inspired warmth with purposeful motion.

## Working agreements
- Keep UI components consistent by reusing shared card, button, and section templates.
- Maintain the Pixel Moose logo lockup (logo left, "Pixel Moose" large, "Studio" small below).
- Favor accessible contrast and responsive layouts for both desktop and mobile.

## Useful commands
- `npm run dev`
- `npm run build`
- `npm run preview`
